> 所有窗口，同一个现在。

## 1. 这个产品是什么

一台服务器上可以开若干个**房间**，每个房间持有**唯一**的一个倒计时。任意多个窗口连进同一个房间，显示同一个剩余时间。操作者在控制台进入房间开始、暂停、延长、结束，房间里所有窗口同时跟着变；房间之间互不影响。

它卖的是**准**，不是炫。界面上的每一个决定，都应该能回答一个问题：这让时间显示得更准、更清楚了吗？

---

## 2. 设计原则

1. **准先于好看。**
   精度是功能，不是指标。等宽数字、单调时钟、延迟补偿、按需重绘，这些用户看不见的东西，比任何动效都重要。
2. **服务器是唯一的时间来源。**
   客户端只负责显示，不自己决定状态。唯一的例外是断线时按最后已知状态继续走时。
3. **断线不停表。**
   网络会断，时间不会。断线时表照走，只在角落安静地标出「连接中」。
4. **零配置。**
   客户端只需要填一个地址，房间就在地址里。不注册、不登录，也不用另外选房间。
5. **克制。**
   一个强调色。不加渐变，不加发光，不加弹跳。
6. **不打扰。**
   提醒是一张小卡片，几秒后自己消失。不进系统通知中心，不抢焦点，不发声音。

## 3. 命名

### 3.1 总规则

> **名词可以带典故，动词必须说人话。**

用户读的是按钮，不是说明书。名字看不懂，顶多觉得古怪；动词看不懂，就会直接卡住。

克制的做法不是删掉典故，而是**把典故放在不承担操作的地方**。

### 3.2 三条约束

1. **十字可解。** 每个带典故的词，必须能用十个字以内解释清楚。做不到，就退回普通说法。
2. **一概念一词。** 同一个概念全产品只用一个词，不为了文采换说法。
   - 例：PRD 初稿里「暂停」和「停止（可再继续）」指的是同一件事，因此合并为「暂停」，界面不再出现「停止」。见 PRD 决策 D-1。
3. **不混排。** 中文界面只用中文，英文界面只用英文。数字和单位符号除外。

### 3.3 三层结构

**品牌层**：可以带气质，用户不会误读。

- 产品名：**Meridian / 子午**。
- 标题只出现一种语言：英文界面写 `Meridian`，中文界面写 `子午`。不写「Meridian 子午」这种双排，那是 logo 锁定组合，不是标题。
- 不加后缀：没有 Meridian Sync，没有子午 Pro。
- 不做缩写：Meridian 缩不出好东西，硬造一个反而廉价。

**程序层**：直白，说明它是什么。

| 角色 | 中文名 | 英文名 | 窗口 / 页面标题 | 仓库目录 | 内部代号 |
| --- | --- | --- | --- | --- | --- |
| 客户端 | 子午 | Meridian | 子午 / Meridian | `client/` | Astrolabe（星盘） |
| 管理端 | 子午控制台 | Meridian Console | 子午 · 控制台 / Meridian · Console | `console/` | Observatory（天文台） |

内部代号只在 README 的「设计说明」里提一句出处，界面上一律不出现。

**界面层**：全大白话。完整词表见 3.4。

## 4. 气质藏在哪里

只有四个地方允许有气质。它们的共同点是：用户不会去读，读到了也不会误解。

### 4.1 关于页，一句话

> 子午线是一条人为画出来的线。
> 不同地方的人约好同一条线，才共享同一个「现在」。
> 这个程序只做一件事：让每个窗口都统一现在是几点。
>
> 所有窗口，同一个现在。

英文版：

> A meridian is a line someone drew.
> People in different places agree on the same line, and so share the same "now".
> This program does one thing: make every window agree on what time it is.
>
> Every window, the same now.

### 4.2 客户端空闲态

未连接时不写「无数据」，写 **「等待信号」**。四个字，安静，不解释。

### 4.3 版本代号用节气

二十四节气本质是太阳黄经每 15° 一格，是严格的天文刻度，而且所有人都认识。24 次发布刚好走完一轮黄道：发布周期本身就是一次公转。

规则：

- 每次对外发布（含修复版本）按顺序取下一个节气，代号与版本号不做固定换算。
- 1.0 定为 **小满**。小满不是大满：可用、够用，不贪多。这是对 1.0 的态度。
- 走完大寒后从立春重新开始，靠版本号区分。
- 中文界面关于页写 `v0.1 · 立春`；英文界面写 `v0.1 · Start of Spring`（用节气的通行英文译名，不写拼音）。

发布计划见 PRD 第 13 节。

### 4.4 图标：一条线

一个圆环，一条竖线从顶贯到底，线上一个点。静止时读作天球剖面；动起来，那个点就是「现在」。

- 网格 24 × 24；圆环直径 18，描边 2；竖线描边 2，上下各出头 1；点直径 4，位于竖线上 1/3 处。
- 16px 托盘尺寸下会塌成「带指针的环」，正好认得出，不会糊。托盘版描边改为 1.5，点直径 3。
- 图标本体单色（墨或纸），只有那个点随状态变色，见 5.8。

## 5. 视觉系统

### 5.1 颜色

界面基本是墨与纸，其余全走灰阶。只留一个彩色给「进行中」。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `bg` | `#F5F5F2` 纸 | `#111418` 墨 | 背景 |
| `fg` | `#111418` 墨 | `#F5F5F2` 纸 | 主文字、主数字 |
| `fg-muted` | `#6B6F74` | `#8D9197` | 次要文字、暂停时的数字 |
| `line` | `#D6D6D1` | `#2E333A` | 1px 边线、分隔线 |
| `track` | `#E4E4DF` | `#22262C` | 进度轨道（未走部分） |
| `accent` | `#E0A94A` 暗琥珀（默认） | `#E0A94A` | **仅**进行中的进度填充；客户端可换色（见 5.2 第 6 条） |
| `alert` | `#C8452F` 朱红 | `#C8452F` | 最后一段的进度与数字、时间到 |

### 5.2 颜色规则

1. **琥珀只做填充，不做文字。** 琥珀在纸色背景上对比度不足 2:1，读不清。数字永远是 `fg`。
2. **朱红只出现在最后一段。** 警示阈值 = min(60 秒, 总时长 × 20%)。总时长 1 分钟的倒计时，最后 12 秒才变红；5 分钟及以上，最后 60 秒变红。进入阈值后，进度填充和数字一起变为 `alert`。
3. **不在走时就没有颜色。** 暂停、未开始、等待信号，进度填充一律退为 `fg-muted`，数字退为 `fg-muted`。
4. **不加渐变，不加发光，不加阴影。** 需要和背后桌面分开时，用 1px `line` 边线代替阴影。
5. 控制台和客户端用同一套 token。控制台的按钮、表单也只用灰阶；危险操作（结束）的确认按钮用 `alert`。
6. **客户端的 `accent` 可换，规则不变。** 预设 8 色都压低了饱和度，和墨、纸放在一起不抢眼：琥珀 `#E0A94A`（默认）、松绿 `#4F8A6E`、青瓷 `#6AA39A`、天青 `#5B9BD5`、靛蓝 `#4A6FA5`、藤紫 `#8A72B0`、胭脂 `#B2506B`、苔绿 `#8A9A4B`。预设里刻意不放红、橙，以免和朱红警示混淆，也不放灰，以免和暂停混淆；自定义成这类颜色由用户自己决定。换色后它仍然只做填充、不做文字，警示段仍然是朱红。品牌标记里的点始终是琥珀。

### 5.3 字体

- **数字**：Inter，随客户端打包（SIL OFL 许可），开启等宽数字（Flutter：`FontFeature.tabularFigures()`；CSS：`font-variant-numeric: tabular-nums`）。否则秒数跳动时整行会抖。
- 大号数字用 Light 或 Regular，不用粗体。数字越大，字重越轻。
- **中文**：跟随系统。Windows 为 Microsoft YaHei UI；控制台网页用系统字体栈，不加载网络字体（考场、内网可能没有外网）。
- **英文正文**：Inter。

### 5.4 时间格式

| 情况 | 格式 | 例 |
| --- | --- | --- |
| 剩余 ≥ 1 小时 | `H:MM:SS` | `1:05:09` |
| 剩余 < 1 小时 | `MM:SS` | `04:59` |
| 超时 | `+MM:SS` / `+H:MM:SS` | `+01:23` |
| 未开始 / 等待信号 | `--:--` | `--:--` |

- 秒数**向上取整**显示：剩余 0.4 秒显示 `00:01`，只有真正归零才显示 `00:00`。这样「00:00」出现的那一刻，就是时间到的那一刻。
- 控制台输入时长时，`15` 理解为 15 分钟，`1:30` 理解为 1 分 30 秒，`1:30:00` 理解为 1 小时 30 分。

### 5.5 形状与线

- 线宽只用 1px（边线）、2px（图标）、以及样式本身的进度粗细。
- 圆角只用两档：4px（按钮、输入框、条形端头）、8px（卡片、提醒卡片、设置面板）。
- 留白以 4px 为基数：4 / 8 / 12 / 16 / 24 / 32。

### 5.6 动效

- 进度走时是**线性**的，不缓动。时间本身是匀速的。
- 状态切换（开始、暂停、结束）用 160ms 淡入淡出；加减时间时进度条用 240ms 匀速补回或退回，让人看见「加上去了 / 减下来了」。
- 进入警示阈值时，琥珀到朱红用 400ms 过渡，只发生一次，不闪烁。
- 提醒卡片：160ms 淡入 + 向内位移 4px；消失 120ms 淡出。
- 不用弹簧、不用回弹、不用缩放脉冲。系统开启「减少动态效果」时，除走时外的所有动效改为直接切换。

### 5.7 状态视觉对照

| 状态 | 数字颜色 | 进度填充 | 附加文字 |
| --- | --- | --- | --- |
| 等待信号（未连接） | `fg-muted`，显示 `--:--` | 无 | 等待信号 |
| 未开始 | `fg-muted`，显示 `--:--` | 无 | 未开始 |
| 进行中 | `fg` | `accent` | — |
| 进行中（警示段） | `alert` | `alert` | — |
| 已暂停 | `fg-muted` | `fg-muted`，冻结 | 已暂停 |
| 时间到 | `alert`，显示 `00:00` 或 `+MM:SS` | 空 | 时间到 |
| 已结束 | `fg-muted` | 空 | 已结束（显示 5 秒后回到「未开始」） |
| 连接中（断线后本地继续走时） | 按当前状态 | 按当前状态 | 角落一个 `fg-muted` 小点，悬停显示「连接中」 |

### 5.8 托盘图标状态

图标本体保持单色，只有竖线上的那个点变：

| 状态 | 点 |
| --- | --- |
| 未连接 | 空心 |
| 已连接，未开始 / 已暂停 / 已结束 | 实心，与本体同色 |
| 进行中 | `accent`（跟随客户端的进度颜色，非默认色时运行时生成图标） |
| 警示段 / 时间到 | `alert` |

本体颜色随任务栏明暗切换（浅色任务栏用墨，深色任务栏用纸）。

## 6. 文案语气

- **说人话。** 能用一个常用词，就不用两个；能不解释，就不解释。
- **出错时告诉下一步。** 不只说「失败」，要说怎么办。
- **不用感叹号。** 时间到了也不用。
- 中文里数字与汉字之间加一个空格：「还剩 5 分钟」。
- 尽量不出现人称；必须出现时用「你」。
- 按钮文字就是动作本身，不加「点击」「请」。

| 不要 | 要 |
| --- | --- |
| 无数据 | 等待信号 |
| 连接失败！ | 连不上这个地址。检查地址是否正确，或服务器是否在运行。 |
| 请点击确认以终止当前倒计时 | 结束后无法继续。确定结束？ |
| 吸附位置 | 贴边 |
| 已成功保存配置 | 已保存 |

## 8. 设计说明（供 README 引用）

产品名取自子午线：一条人为约定的线，让不同地方的人共享同一个「现在」。

两个程序的内部代号：客户端 **Astrolabe（星盘）**，手里拿的、看时间的仪器；控制台 **Observatory（天文台）**，发布时间的地方。

早期构想曾用一组天文词汇命名功能，后来全部收回，只留在这里作为出处：

| 曾用词 | 原意 | 现在界面上叫 |
| --- | --- | --- |
| 时角 | 天体离开子午线的角距离 | 剩余 |
| 相位 | 天体所处的阶段 | 状态 |
| 历元 | 计算的起始参考时刻 | （开始时刻，界面不显示） |
| 弧 | 天体走过的一段轨迹 | 进度 |
| 掩 | 一个天体遮住另一个 | 暂停 |
| 逆行 | 行星看起来往回走 | 延长剩余时间 |
| 展弧 | 把弧拉长 | 延长总时长 |

> 注：以上对照是整理时依据词义补出的推断，初版构想里没有逐一写明。如果原本另有所指，以原意为准修订此表。

它们很好听，但用户读的是按钮，不是说明书。
